# Support

Use the channel that matches the problem:

- Product questions and community help: the official Post Fiat community link
  at <https://postfiat.org/community/>.
- Reproducible source defects: GitHub Issues, after removing personal data,
  credentials, production logs, wallet identifiers, and private content.
- Security vulnerabilities: private reporting only, as described in
  `SECURITY.md`.
- Account data deletion: Settings -> Data controls -> Delete account in the
  deployed Task Node application.

Public maintainers cannot recover wallet phrases or private keys, reverse a
signed public-chain transaction, delete data retained by independent Nostr or
IPFS operators, or diagnose a private account from secrets pasted into an
issue. Never send a wallet recovery phrase to support.

The public source repository does not grant access to or operational support
for the official hosted service. Production incidents and operator requests
use the private operations process.
