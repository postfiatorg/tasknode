## What Could Go Wrong

- Help lists a prompt as active but runtime uses hard-coded prompt text.
- Prompt files change without version/digest updates where output becomes
  durable.
- A `usedBy` entry points to a stale or nonexistent call site.
- Reserved prompts look production-active.

## Best Practices To Check

- Runtime prompt text should come from source-controlled prompt files or have a
  documented compatibility reason.
- Durable model output should record prompt version and digest.
- App-visible prompt docs should distinguish active, reserved, and reference-only
  prompts.
