# Dark mode implementation — September 8, 2026

## Behavior

Account menu → Settings → General → Appearance offers native System / Light / Dark radios as the first row. Changes are immediate and saved under `tasknode.appearance.v1` for this origin/device, independently of account state. Storage failures show a session-only note. A synchronous, same-origin `theme-init.js` resolves the root background, `data-theme`, `color-scheme`, and browser theme color before React mounts. The React subscription owns live OS/storage listeners; standalone auth pages use `theme-page.js` with page lifecycle cleanup. Both unversioned assets have `Cache-Control: no-store`.

Warm charcoal semantic roles cover 33 existing CSS files plus Profile's inline palette, task status inline colors, and standalone Telegram/terminal auth pages. Each migrated CSS value keeps its exact original light fallback; a source comparison found 33/33 stylesheets identical after removing the dark-role wrappers. Images and generated artwork remain unchanged. Print resets the theme roles to their light palette. No backend preferences, migrations, secrets, provider calls, or billing changes are required.
