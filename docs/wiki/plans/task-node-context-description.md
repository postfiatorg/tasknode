## Replacement Paragraph

Task Node is an AI-assisted work app for people trying to make better decisions
and do better work while managing too much complexity. The user keeps a live
Context document that explains who they are, what they are building, what
matters now, and what constraints the system should remember. Chat helps the
user think, draft, decide, and understand the app. Help explains each surface in
plain English. Tasks turn context into concrete work: a user can request a
personal task, accept or refuse it, complete the work, submit evidence, and
receive PFT when the task is rewarded. Hive is the group layer: it routes
Network Tasks for shared Post Fiat projects and helps contributors see what the
network is working on. Wallet handles PFT identity, signing, rewards, top-ups,
and custody boundaries. Profile shows reputation, task history, daily airdrop
state, recommended connections, and NFTs. The goal is not chat for its own sake.
The goal is a trustworthy loop from context to decision to work to proof to
reward.

## Honest PFTasks Evaluation

PFTasks was the first attempt at this idea, but it was not a coherent product.
It proved that task generation, PFT rewards, wallet identity, and AI-assisted
work could belong together, but the user experience was too fragile and too hard
to understand. State was confusing, task quality was inconsistent, wallet and
identity boundaries were not clear enough, and too much of the system depended
on the founder understanding hidden implementation details. PFTasks was useful
as a prototype and evidence source. It was not good enough as the main product
surface.

Task Node is the rebuild. The point is to keep the useful idea from PFTasks
while removing the confusion: clearer surfaces, clearer wallet custody, clearer
task states, better Help, better Context, better Hive routing, and a task loop
that a normal user can understand without being coached.
