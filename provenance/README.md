# Provenance

`assets.json` is the allowlist for non-code assets in the public release
candidate. Every listed hash must match the file, and every candidate image,
font, video, audio file, or PDF must have an entry. Official project-brand
assets remain governed by `TRADEMARKS.md`; presence in a source release does
not relicense the marks.

Generated verification screenshots, historical design mocks, operator output,
and marketing working files are not part of the public candidate. New assets
must identify an owner, original source, applicable terms, and exact SHA-256.
