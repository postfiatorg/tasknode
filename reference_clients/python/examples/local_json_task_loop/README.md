# Local JSON Task Loop Demo

This demo is a deterministic, local-only Task Node workflow. It does not use
PFTL, IPFS, Postgres, OpenAI, or wallet credentials. It exists to show the full
task loop in a form that can be run and audited from a clean checkout.

The CLI executes:

1. Create a canonical task request.
2. Generate a deterministic task ID and task offer.
3. Accept the task.
4. Write an evidence artifact.
5. Review the artifact.
6. Update local reputation state.
7. Persist every state transition as JSON.

Run from the repository root:

```bash
PYTHONPATH=reference_clients/python python -m tasknode_pftl.scenarios.local_json_task_loop --reset
```

Expected output:

```text
Task Node local JSON loop complete
  task_id: task_56e4026772be18750692279d
  task_generated: none -> proposed
  task_accepted: proposed -> accepted
  artifact_submitted: accepted -> submitted
  submission_reviewed: submitted -> reviewed
  reputation_updated: reviewed -> rewarded
  reputation_points: 42 -> 50
```

Persisted outputs are in `state/`:

- `events.json` - canonical event log and visible state transitions.
- `tasks.json` - task projection after generation, acceptance, submission,
  review, reward, and reputation update.
- `artifacts.json` - submitted evidence artifact metadata and digest.
- `reputation.json` - updated local reputation state.
- `receipt.json` - end-to-end receipt with deterministic IDs and state digest.
- `artifacts/*.md` - the evidence body submitted into the local workflow.

The committed `state/` directory is generated by the exact command above and is
included as review evidence.
